# Warudo-Average-Float-Node
Adds a node that returns the average of 2 input floats. Useful for keeping a cleaner node setup

## Installation
Subscribe to the [Steam Workshop item](https://steamcommunity.com/sharedfiles/filedetails/?id=3683183308)

## Manual Installation
Download the [AverageFloatNode.cs](https://github.com/MooshPaw/Warudo-Average-Float-Node/blob/main/AverageFloatNode.cs) on your ``Warudo\Warudo_Data\StreamingAssets\Playground`` folder
